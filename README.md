# Cat Steps

A beginner-friendly daily cat-training guide with 30 self-paced practice days, clicker instructions, a six-panel illustration, video resources, a timer, notes, and device-local progress.

## Use it

Open `index.html` in a browser. No installation, account, or build is needed. Keep the `assets` folder and both JavaScript files beside it. Internet is only needed for external video and source links.

The schedule is a suggested practice sequence, not a deadline or professional assessment. Repeat lessons until your cat participates comfortably. Every click is followed by a reward. Training never substitutes for veterinary evaluation of pain or sudden behavior changes.

## Privacy

Notes and progress are stored only in the current browser using localStorage. Nothing is sent to a server. Saving on a file URL can depend on browser settings. A web-hosted copy has its own separate saved state. There are no automatic reminders, tracking scripts, or analytics.

## Content and media

Written daily progression is an original suggested practice plan informed by the sources linked in the guide. Third-party videos are linked, not copied or hosted. The training illustration was generated with the built-in image generation tool; its prompt is in `assets/image-prompt.txt`. It is illustrative and not a substitute for written instructions.

## Share on GitHub

This folder is the complete project. A public repository shares the source and assets. A browser-hosted version requires separate hosting; creating a repository alone does not create a live website.

## Verify

Open the guide and check day selection, checkbox persistence after reload, notes, section navigation, timer pause/reset, and the illustration. JavaScript syntax can be checked with `node --check app.js` and `node --check lessons.js`.
